# LSTS AI+ typography

`inter-var.woff2` is the variable web font from the [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1). It includes Latin and Vietnamese glyphs and is bundled under the [SIL Open Font License](Inter-OFL.txt).

`public/css/lsts-typography.css` loads the font for the application and specifies the fallback stack.
